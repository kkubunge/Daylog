# 데이로그 (Daylog)

폰 안의 **사진 · 통화 · 문자 · SNS 기록**을 바탕으로 부담 없이 짧은 오늘 일기 베이스를 자동 취합해 주고, 내가 원할 때 1~2줄만 다듬어 **과거의 기억을 회상**할 수 있는 데일리 일기장 안드로이드 앱입니다.

---

## 핵심 컨셉 & 주요 기능

1. **자동 취합 + 자유로운 수정 (`PhoneDataCollector` + `AutoDraftGenerator`)**
   - 갤러리 사진(`MediaStore`), 통화 내역(`CallLog`), 일상 문자(`Telephony.Sms`), SNS 알림(`NotificationListenerService`)을 날짜별로 모아 1~3줄짜리 짧은 일기 초안을 자동 작성합니다.
   - 자동 생성된 초안은 언제든 직접 수정 가능하며, 한 번 수정한 날의 글과 사진은 재취합 시에도 보존됩니다.
2. **임팩트 있는 대표 이미지 1~2장 자동 선별 (`PhotoImpactScorer`)**
   - 카메라 촬영 여부, 해상도, 종횡비, 촬영 시각 분산을 기준으로 스크린샷·연사 중복을 피해 그날을 대표하는 사진 1~2장을 뽑아 폴라로이드 형태로 담습니다.
   - 상세 화면에서 후보 사진 중 직접 고르거나 시스템 갤러리에서 교체할 수 있습니다.
3. **SNS 기록 자동 수집 & 외부 앱 공유 (`DaylogNotificationListener` & `ACTION_SEND`)**
   - 알림 접근 권한을 연결하면 카카오톡, 인스타그램, 스레드, 텔레그램, 라인, X 등의 알림을 자동 요약해 기록합니다.
   - 인스타/유튜브/갤러리 등에서 `공유하기 → 데이로그`를 선택하면 오늘 일기에 바로 추가됩니다.
4. **스팸/광고 문자 필터링 (`SmsSpamFilter`)**
   - `[Web발신]`, `(광고)`, 인증번호, 카드 승인, 택배 알림 등 기계적 문자는 자동으로 걸러내고 일상 대화만 남깁니다.
5. **과거 추억 회상 & 포토 달력 (`MemoryRecallEngine`)**
   - **1주 전 오늘 / 1개월 전 오늘 / 1년 전 오늘**, **책갈피**, **랜덤 추억 꺼내기**로 지나간 소소한 날들을 다시 꺼내 볼 수 있습니다.
   - 선택적으로 Gemini API 키를 설정하면 수집된 조각들을 바탕으로 한 줄 다듬기 기능을 사용할 수 있습니다.

---

## 빌드 안내

- `.github/workflows/android-build.yml` 이 `master` 푸시마다 단위 테스트(`testDebugUnitTest`)와 디버그 APK(`assembleDebug`) 빌드를 자동 수행합니다.
- 모든 개인 데이터(일기, SNS 알림 조각, 설정)는 기기 내부에만 저장되며 외부 서버로 전송되지 않습니다.
