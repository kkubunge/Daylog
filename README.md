# 데이로그 (Daylog)

달력에서 원하는 날짜를 터치하면 그날 있었던 **이동·체류 장소(GPS), 촬영 사진, 통화, 문자, SNS 알림, 메모** 데이터를 한눈에 조회할 수 있는 깔끔한 모노톤 라이프로그 안드로이드 앱입니다.

---

## 주요 기능

1. **첫 화면 달력 & 일자별 데이터 즉시 조회 (`CalendarScreen`)**
   - 앱을 열면 깔끔한 무채색 월간 달력이 바로 표시됩니다.
   - 어떤 날짜든 터치하면 해당 날짜의 요약 건수(장소·사진·통화·문자·SNS)와 상세 타임라인을 즉시 조회합니다.
2. **이동 및 체류 장소 타임라인 (`LocationTrackerService` + `PlaceVisitEngine`)**
   - 백그라운드 GPS 자동 기록을 켜두면 150m 이상 이동 시 새 장소를 기록하고 머무른 시간과 이동 거리(`m` / `km`)를 계산합니다.
   - 과거 날짜라도 사진 파일에 EXIF GPS 위치 정보가 남아 있으면 좌표를 읽어 역지오코딩(`Geocoder`)으로 방문 장소를 복원합니다.
   - 자주 가는 장소(예: `집`, `회사`)에 이름을 저장해 두면 반경 150m 이내 방문 시 자동으로 해당 장소명으로 표시되며, 장소를 탭하면 지도 앱으로 바로 열 수 있습니다.
3. **시간순 활동 통합 조회 (`PhoneDataCollector` & `DaylogNotificationListener`)**
   - **사진**: 촬영 시각 및 위치 라벨과 함께 가로 스트립/격자로 조회 및 원본 확대
   - **통화**: 수신·발신·부재중 내역 및 통화 시간, 연락처 이름 매핑
   - **문자**: 광고·인증번호·결제·택배 스팸을 걸러낸 일상 문자 내역
   - **SNS 알림**: 카카오톡·인스타그램·스레드·텔레그램·라인·X 등의 알림 및 외부 앱 `공유하기` 수신 기록
4. **전체 기록 검색 & 이동 장소 탭 (`FeedScreen`, `PlacesScreen`)**
   - 날짜별 전체 데이터를 장소·연락처·문자/SNS 키워드로 검색하고, 자주 방문한 장소와 등록된 별칭을 관리할 수 있습니다.
5. **Gemini AI 데이터 도우미 (`GeminiClient`, 선택 기능)**
   - 설정에 Gemini API 키를 입력하면 ① **AI 데이터 브리핑**(이동 동선·통화·약속/중요 정보 요약), ② **AI 자연어 기록 검색**("지난주 판교 갔던 날 찾아줘" 등 질문 후 해당 날짜로 바로 이동), ③ **사진 내용/영수증 읽기**(사진 확대 화면에서 상호·금액·문서 텍스트 추출)를 사용할 수 있습니다.
